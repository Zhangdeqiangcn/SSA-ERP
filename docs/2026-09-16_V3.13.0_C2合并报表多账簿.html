二、合并发动机怎么算（核心逻辑）

合并报表的本质只有两步：
  1. 汇总：把参与合并的各个会计主体（各账套 / 各公司）的凭证，按科目汇总借贷；
  2. 抵消：把母子公司之间的内部往来互相抵消——母公司应收 = 子公司应付，合并后应压成 0，否则收入利润凭空翻倍。
本版做了两个口径（scope）：
scope含义本版处理
books同组织内的多套账合并门禁主验证路径（见第三节）
group集团跨组织合并（母公司 + 子公司）基础设施已建好：orgs 集团化字段 + group scope + 跨组织权限闸门（非成员 403），待联调
