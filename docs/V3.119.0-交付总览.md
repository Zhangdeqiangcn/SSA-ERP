## 一、做了什么

按强哥要求「采用与采购订单列表同一套做法」，把三大模块共 15 个列表接入同一套 `useTypedRelated` 关联体系。至此采购 / 质量 / 生产 / 财务 / 销售 / 价格 / 仓储**七大域全部同源**。

| 模块 | 页面 | 接入前 | 接入后 |
|---|---|---|---|
| 销售（6） | 销售订单 / 销售合同 / 发货管理 / 商机 / 项目管理 / 销售报价单 | 旧版两列「来源单据 / 后续单据」，且被 `hiddenColumns` 隐藏 | 按真实单据类型动态分列 |
| 价格（4） | 价目表 / 询价单 / 比价单 / 价格审批 | 同上 | 同上 |
| 仓储（5） | 出库单 / 成品入库 / 报检单 / 波次拣货 / 盘点任务 | 同上 | 同上 |

统一效果：列头即单据中文名、单元格「单号 + 状态 Chip」、点单号直达详情、关联列参与检索。

## 二、顺带修出的真缺陷

### 8 处关系定义缺陷（`src/utils/relations/relations.ts`）

共性：**不报错、不崩溃，只是永远匹配不到**。这是最隐蔽的一类。

| # | 单据 | 缺陷 | 后果 |
|---|---|---|---|
| 1 | 商机 | 缺 `matchField:'id'` | 拿商机单号 `PRO202406001` 去比报价单 `sourceProspectId` 存的 `pro-001`，**列恒空** |
| 2 | 询价单 | 采购申请号在明细行，却用 `upstream:{field}` 读单据头 | 采购申请列恒空 |
| 3 | PDCA | `sourceType/sourceNo` 在类型上不存在 | 纯死代码 |
| 4 | 报检单 | 检验任务表无 `noticeNo` 字段 | 检验任务列恒空 |
| 5 | 不合格品 | `linkedOutboundNo/linkedInboundNo` 是本单字段 | downstream **方向写反** |
| 6 | 检验任务/批次 | `{target:'pdca', linkField:'sourceNo'}` 死代码 | 无 |
| 7 | 框架协议 | 引用不存在的 `PurchaseOrder.releases` | 无 |
| 8 | 三方代销 | `toRef` 收单号却传了 id | 客户列恒空 |

### 8 处种子数据断层

- 工单号两套体系并存（`WO20240515001` vs `WO-2024-0501`），7 处对齐
- 补缺失工单 `wo-c1-001`，使 C1 批次追溯链路闭环
- 销售合同从 2026 年迁到 2024 年（原与全站销售单据时间线永不重叠）
- 销售报价单从孤岛接入业务链
- 销售订单补合同引用、波次拣货明细改为真实订单与物料编码

## 三、★ 方法论沉淀

**「关联列为空」有三类完全不同的成因，必须分层排查：**

1. **关系定义错** —— 不报错不崩溃，只是永远匹配不到（本轮 8 处）
2. **种子数据断层** —— 关系对了，但引用的单号在目标表不存在
3. **数据模型缺失** —— 类型里根本没有可用字段（三方代销、盘点任务）

## 五、复核阶段修正的三处探针误判（如实记录）

初次统计给出的是「31 列 / 14 页 / 7 处死链」，复核后证明都是探针问题：

1. **路由凭命名猜错** —— `/sales/quotations` 等 6 个路径根本不存在，6 个页面被判「无关联列」
2. **dev 登录态伪造** —— 自己写假 token 反而阻断了 `authStore` 的自动注入，全站空表
3. **单元格按下标取** —— DataTable 虚拟滚动有 `colSpan` 占位行，按下标会串到相邻列，7 处「死链」全是假象

## 六、诚实边界

- **盘点任务刻意不连**：与库存调整单无任何共用单号，按「同仓库+同日期」猜会造错误关联，宁可列空
- **三方代销只接客户外键**：`TripartySale` 只有 `docNo/partyCode/customerId/materialCode`，无任何指向其他单据的单号字段，属数据模型缺失
- **4 个整列为空**：销售订单→销售报价单、发货管理→出库单、出库单→序列号、出库单→记账凭证，均为种子未填
- **`mes.ts` 不动**：工单号与产品与工单表完全不同源
- **生产冒烟未完成**：两个账号在生产 `/api/auth/login` 均返回密码错误（`/api/health` 为 200，后端正常），属账号侧问题，非本版引入
- 盘点任务页 2 个「操作」表头：该页本身有两张表，属既有现象
