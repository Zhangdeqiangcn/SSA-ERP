# SSA ERP V2.34 手动测试步骤（A5 退货红冲税额修复）

> 版本：V2.34（2026-08-05）　模块：销售退货·采购退货（税务凭证严谨性 A5）　专项 E2E：`e2e/v55-a5-return-tax.spec.ts`（3 例全绿）
> 范围：根治「退货红冲税额写死 0」顽疾——销售退货红字发票税额 + AR 红冲销项税额 + 应收账款含税；采购退货应付含税 + 补进项税红冲。两处凭证均借贷配平。

---

## 一、销售退货红冲税额（A5-①，对标 SAP/金蝶/用友 税务凭证严谨性）

### 1.1 业务背景与修复点
- 旧逻辑 `salesAdvancedStore.completeReturn` 把红字发票行项写成 `taxRate:13, taxAmount:0`（税额写死 0）、AR 红冲凭证销项税额 `amount:0` 且应收账款用净额（未含税）。
- 修复后：税率优先取**原销售订单 SO 行项 `taxRate`**（缺省回退 `utils/tax.ts` 的 `DEFAULT_TAX_RATE=13`）；红字发票与 AR 红冲均按实际税率计算税额与价税合计。

### 1.2 走查步骤
- 进入 **销售管理 → 退货单 → 新建**，关联一张已有销售订单（含税率行项，如 13%），填退货数量 → 保存为草稿。
- 点「完成退货」（completeReturn）→ 系统自动：
  1. 生成**红字发票**（invoiceType='credit_note'）：行项 `taxAmount = 数量×单价×税率/100`，头 `amount`(不含税净额) / `taxAmount`(税额) / `totalAmount`(价税合计=净额+税额)。
  2. 生成 **AR 红冲凭证**，三笔分录：
     - 借 `主营业务收入`（净额）
     - 借 `应交税费-应交增值税`（销项税额红字，金额 = 税额，**非 0**）
     - 贷 `应收账款`（**价税合计，含税**）
  3. 三笔借贷合计相等（借贷平衡）。

### 1.3 验证要点（数值例）
- 退货净额 1000、税率 13% → 红字发票 `taxAmount≈130`、`totalAmount≈1130`；凭证销项税额 `≈130`、应收账款 `≈1130`、借贷平衡、共 3 笔。

---

## 二、采购退货红冲税额（A5-②）

### 2.1 业务背景与修复点
- 旧逻辑 `purchaseAdvancedStore.completeReturn` 应付冲销仅「借应付账款 / 贷原材料」两笔，应付用**净额（未含税）**，且**缺失进项税红冲**分录。
- 修复后：税率优先取**原采购订单 PO 行项 `taxRate`**（缺省回退 13）；应付冲销改为价税合计，并补一笔进项税红冲。

### 2.2 走查步骤
- 进入 **采购管理 → 退货单 → 新建**，关联一张已有采购订单（含税率行项，如 13%），填退货数量 → 保存为草稿。
- 点「完成退货」（completeReturn）→ 系统自动生成 **AP 冲销凭证**，三笔分录：
  - 借 `应付账款`（**价税合计，含税**）
  - 贷 `原材料`（净额不变）
  - 贷 `应交税费-应交增值税`（**进项税额红字**，金额 = 税额，修复后新增）

### 2.3 验证要点（数值例）
- 退货净额 2000、税率 13% → 应付 `≈2260`（2000+260）、原材料 `≈2000`、进项税红冲 `≈260`、借贷平衡、共 3 笔。

---

## 三、借贷平衡与幂等（A5-③）

### 3.1 借贷平衡
- 上述两类红冲凭证，借合计 = 贷合计（容差 0.005），总账不会因红冲而失衡。

### 3.2 幂等
- 同一退货单号重复点「完成退货」→ 状态已完成被守卫拦截，**不会重复生成凭证**（凭证数不变）。

---

## 四、回归关注点（A5 专项之外）
- 全量 E2E **40 spec / 158 用例**：A5 新增 1 spec（v55，3 例）；唯一偶发失败仍为 `v31` 菜单定制 persisted-state flake（隔离重跑 7/7 全绿），非产品回归。
- 与退货相关的既有 `v43-p3-3.spec.ts`（采购退货）断言只校验应付冲销分录存在 + 红字出库 + 状态，**未断言税额 0**，故 A5 修复不破坏它（实测 9/9 全绿）。
- 影响面严格限定在 `salesAdvancedStore` / `purchaseAdvancedStore` 两个退货 store 的税额逻辑，其他模块（成本核算 A4 / 客户主数据 A3 / 税价拆分 A2 / 凭证结构 A1）全部不受影响。
