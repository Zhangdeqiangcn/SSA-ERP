# SSA ERP V2.33 手动测试步骤（A4 成本核算闭环）

> 版本：V2.33（2026-08-05）　模块：仓储·成本核算（A4）　专项 E2E：`e2e/v52-a4-movingavg.spec.ts` / `v53-a4-cogs.spec.ts` / `v54-a4-grir.spec.ts`（各 3 例，共 9/9 全绿）
> 范围：移动平均价滚动 + 出库 COGS 凭证 + GR/IR 暂估三块分步交付；存货只在收货入账一次，发票校验仅冲暂估+确认应付。

---

## 一、移动平均价滚动（A4-①，对标 SAP MBEW）

### 1.1 入库过账自动滚价
- 进入 **仓储管理 → 入库单 → 新建**，类型选 **采购入库**，选物料、填实收数量与未税单价（或留空由采购订单回查）。
- 保存并「确认入库」（status=completed）→ 系统自动：
  - 按 `(原库存金额 + 本次入库未税金额) / (原库存数量 + 本次入库数量)` 重算 **移动平均价**；
  - 回写物料主数据 `movingAvgPrice` / `stockValue` / `currentStock`，满足恒等式 `stockValue ≈ currentStock × movingAvgPrice`。
- 重复以同一入库单号确认入库 → 移动平均价与库存**不变**（幂等，靠 `costPosted` 标记拦截）。

### 1.2 估值页只读校验
- 进入 **物料管理 → 估值**（MaterialValuation）。
- 「移动平均价」「库存金额」两列**只读展示**（实际滚动值），页面顶部 Alert 提示「由出入库过账自动滚动，不可手改」。
- 物料编辑弹窗中「移动平均价」输入框已改为只读 Alert，无法手改（避免破坏恒等式）。

---

## 二、出库 COGS 凭证（A4-②）

### 2.1 销售出库结转成本
- 进入 **仓储管理 → 出库单 → 新建**，类型选 **销售出库**，选物料、填数量。
- 确认出库（status=completed）→ 自动按当前移动平均价结转：
  - 凭证：`借 6401 主营业务成本 / 贷 1405 库存商品`（金额 = 数量 × 移动平均价）；
  - 物料主数据 `currentStock` / `stockValue` 同步扣减（保持恒等式）。

### 2.2 生产领料结转成本
- 新建出库单，类型选 **生产领料** → 确认出库：
  - 凭证：`借 5001 生产成本 / 贷 1403 原材料`（金额 = 数量 × 移动平均价）。

### 2.3 幂等校验
- 同一出库单号重复确认出库 → 库存只减一次、凭证只生成一张（靠 `alreadyPosted`/`cogsPosted` 标记拦截）。

## 三、GR/IR 暂估（A4-③，对标 SAP GR/IR 清算）

### 3.1 采购收货挂暂估
- 新建**采购入库**（type='purchase'）并确认 → 除滚价外，额外生成暂估凭证：
  - `借 1403 原材料 / 贷 2201 物资采购（GR/IR暂估）`（金额 = 本次入库未税合计 totalCost）。
- 非采购入库（退货/转储）不挂暂估。

### 3.2 发票校验冲暂估 + 确认应付
- 进入 **财务管理 → 发票 → 新建**，填供应商、未税金额、税额、价税合计（价税合计 = 未税 + 税额）。
- 点「生成凭证」（generateVoucherFromInvoice）→ 自动生成：
  - `借 2201 物资采购（GR/IR暂估）`（冲收货时挂的暂估，金额 = 未税）
  - `借 2221 应交税费-应交增值税`（进项税额）
  - `贷 2202 应付账款`（金额 = 价税合计）
- **重点**：旧逻辑「借原材料」会导致存货重复入账，已改为冲暂估+确认应付，存货只在收货入账一次。

### 3.3 GR/IR 全程对账（暂估归零）
- 收货后查 2201 科目：**贷方挂账 = totalCost**（暂估负债）。
- 发票校验后查 2201：**借方冲销 = 同额**，净余额归零（暂估已清算）。
- 同一发票重复「生成凭证」→ 返回 null、不再产生新凭证（`voucherGenerated` 幂等）。

## 四、回归关注点（A4 专项之外）
- 全量 E2E 155 用例：154 通过，1 例 `v31` 菜单定制为已知 persisted-state flake（隔离重跑 7/7 全绿），非产品回归。
- 凭证引擎（A1）不受影响：GR/IR 与 COGS 凭证均走 `createVoucher` 现代引擎，借贷平衡校验生效。
- 科目表新增 `2201 物资采购（GR/IR暂估）`、`5001 生产成本`，三大报表取数口径不变。

## 五、验收结论
- A4-① `v52-a4-movingavg.spec.ts`：滚价 / 幂等 / 估值页只读，**3/3 全绿**。
- A4-② `v53-a4-cogs.spec.ts`：销售出库 / 生产领料 / 幂等，**3/3 全绿**。
- A4-③ `v54-a4-grir.spec.ts`：收货暂估 / 发票校验冲暂估 / 全程对账归零+幂等，**3/3 全绿**。
- 成本核算断链（移动平均价不滚动 / 出库无 COGS 凭证 / 无 GR-IR 暂估）三项顽疾全部根治。
