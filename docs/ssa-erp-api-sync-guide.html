V3.68.0 交付说明 —— 对任意业务表「读 / 写 / 改 / 删」能力 + 对接外部 ERP 双向同步备份（推送 / 拉取），不绑定任何品牌。

一、新增能力总览

① 统一数据接口 /api/data/[table]

把"对任意业务表的增删改查"抽成通用接口，覆盖现有 52 个实体路由之外的全部业务表（D1 实际约 138 张）。返回数据库原始列名（蛇形命名），定位为组织级数据集成接口。

② 通用 ERP 同步引擎 erpSync.ts

可配置 REST 适配器：一份"连接配置"描述对方地址、鉴权方式、字段映射。支持 推送（本系统→外部）与 拉取（外部→本系统，等效异地互备），增量游标 + 幂等 + 失败聚合不中断。

两项能力均复用既有底座：API Key 网关鉴权、行级权限（登记即放行）、审计留痕、列交集过滤、组织隔离——不重造轮子。前端零改动。

二、接口清单

数据读写接口（需 API Key 作用域 read / write，或管理员会话）

方法路径说明权限
GET/api/data/<表名>列表（分页 page/pageSize、filter 按列等值、sort/order）read
POST/api/data/<表名>新增一行（强制 org_id，明细表校验父单归属）write
GET/api/data/<表名>/<id>读取单条read
PUT/api/data/<表名>/<id>更新单条write
DELETE/api/data/<表名>/<id>删除单条write
POST/api/data/<表名>/bulk批量 {mode:'upsert'|'delete', rows:[]}，幂等、失败聚合不中断write

同步管理接口（组织级配置，需管理员）

方法路径说明
GET/api/system/erp-sync连接列表 + 最近运行
POST/api/system/erp-sync新建连接（auth_config 返回时脱敏）
GET/api/system/erp-sync/<id>连接详情 + 运行历史
PUT/api/system/erp-sync/<id>更新连接
DELETE/api/system/erp-sync/<id>级联删除（含运行历史）
POST/api/system/erp-sync/<id>/run触发同步，参数 {direction:'push'|'pull'|'both', full?:true}
POST/api/system/erp-sync/<id>/test连通性测试
系统表（会话 / 密钥 / 系统配置等）天然被排除，不可通过数据接口访问；明细表写入前校验其父单属于本组织，杜绝越界灌数据。

三、鉴权（API Key 网关）

数据接口两种身份可用：

  • API Key（推荐用于系统集成）：请求头 Authorization: Bearer sk_xxxx，按密钥绑定的作用域 read / write / * 放行。
  • 管理员会话：登录态（super_admin / admin），等同 * 作用域。

写入时一律强制 org_id = 请求方组织，绝不接受客户端传来的 org_id，从根源杜绝跨组织越界。

四、典型用法示例

1）读取某业务表（如物料）前 50 行

curl -H "Authorization: Bearer sk_xxxx" \
  "https://你的域名/api/data/materials?page=1&pageSize=50"

2）新建一条外部 ERP 连接（拉取方向，无鉴权示例）

curl -X POST -H "Authorization: Bearer sk_xxxx" -H "Content-Type: application/json" \
  -d '{
    "name":"金蝶备份源", "target_type":"rest",
    "base_url":"https://erp-b.example.com/api",
    "auth_type":"bearer", "auth_config":{"token":"对方令牌"},
    "direction":"pull",
    "mapping_profile":{
      "pullTables":{
        "materials":{ "localTable":"materials", "idField":"id",
          "fields":{ "id":"id", "name":"material_name", "spec":"spec" } }
      }
    }
  }' https://你的域名/api/system/erp-sync

3）触发一次拉取（外部 → 本系统，等效互备）

curl -X POST -H "Authorization: Bearer sk_xxxx" \
  -d '{"direction":"pull"}' \
  https://你的域名/api/system/erp-sync/<连接ID>/run

4）触发一次推送（本系统 → 外部）

curl -X POST -H "Authorization: Bearer sk_xxxx" \
  -d '{"direction":"push","full":true}' \
  https://你的域名/api/system/erp-sync/<连接ID>/run
每次同步都会写 erp_sync_runs（运行历史）与 erp_sync_run_items（逐行结果），哪一行成功/失败、为何失败均可精确复盘；连接级 last_synced_at 自动推进，下次仅增量同步。

五、设计要点与安全边界

  • 通用可配置：bearer / basic / apikey / none 四种鉴权；字段映射模板驱动，金蝶 / 用友 / SAP / 自建系统皆可对接，无需改代码。
  • 双向互备：推送=本系统数据备份到外部；拉取=外部数据回写本系统（复用统一数据接口的安全网：组织隔离 + 审计 + 列交集 + 父单校验）。
  • 幂等：推送带本地 id 作对方主键；拉取以对方 id 作本地主键，重复跑不建重。
  • 失败聚合不中断：单条/单次请求失败只记进 run_items + errors，整轮继续，最终状态 success / partial / failed 精确反映。
  • 诚实边界：仅后端 API + 同步引擎，页面零改；字段映射/方向/鉴权完全可配置；增量游标基于 last_synced_at，首次为全量。
