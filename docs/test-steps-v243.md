## 一、背景
旧版 AQL 抽样计算器（`质量/AQL抽样`）是 **localStorage 数据孤岛**：算出的样本量方案无法带入检验任务，检验员仍需手填抽样数量，存在「算一套、填一套」的脱节。

B9 把 GB/T 2828.1 抽样逻辑抽成共享模块 `src/utils/aql.ts`，**新建检验任务时直接选「检验水平 + AQL%」，系统按批量自动算样本量 n / 接收数 Ac / 拒收数 Re，回填抽样数量并写入检验记录 store**，详情页展示完整抽样方案。

---

## 二、手动验证清单

### 用例 1：新建检验任务自动算 AQL 抽样方案
1. 进入「质量 → 质量检验」。
2. 点「新建检验任务」。
3. 填「物料编码 / 物料名称」（如 `B9-CODE-001` / `B9-AQL-连接件`）。
4. 「检验数量」填 `500`，「检验水平」保持 `II`、「AQL」保持 `2.5%`。
5. 观察：
   - 「抽样数量」自动回填为 **50**；
   - 出现蓝色提示条「抽样方案（GB/T 2828.1）：字码 **H** · 样本量 n=**50** · 接收数 Ac=**3** · 拒收数 Re=**4**」。
6. 点「创建」。
7. 在列表找到该任务，点「查看详情」→ 基本信息区出现蓝色「AQL 抽样方案（GB/T 2828.1）」块，含 字码 H / n=50 / Ac=3 / Re=4。

### 用例 2：切换 AQL / 检验水平重算
- 检验数量 500，`II/2.5%` → n=50；
- 切「检验水平=III」→ 字码 J，n=**80**；
- 再切「AQL=4.0%」→ 字码 J，n=80，Ac=**5** / Re=**6**。
- 抽样数量随方案实时刷新（可手动再改，用于特采/加严等场景）。

### 用例 3：AQL 抽样方案页（独立计算器，回归）
- 进入「质量 → AQL抽样」，默认 批量500/水平II/AQL2.5% → 抽样数量自动回填 50（v34 持续生效）。

## 三、验收口径
- 抽样方案严格按 GB/T 2828.1 正常检验一次抽样（含 `↓` 降码、`↑` Ac=0/Re=1 特例）。
- 数据进入 `qualityStore`（`ssa-erp-quality` persist），刷新后检验任务的抽样方案不丢失。
- 无整页白屏、无 console 报错（E2E 已断言 `pageerror` 为空）。

## 四、回滚与兼容
- `InspectionTask.aql*` 为可选字段，旧任务无该字段时详情页不显示抽样方案块，向后兼容。
- `src/utils/aql.ts` 为纯函数模块，无副作用，不影响现有 AQL 独立计算器行为。
