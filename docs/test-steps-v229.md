# SSA ERP V2.29 采购申请增强（F8）手动测试步骤

> 适用范围：采购申请新建/编辑（路径：采购管理 → 采购申请 → 新建采购申请，或直接访问 `/purchase/create`）
> 前置：dev server 已启动（`localhost:3000`），以有采购申请权限的账号登录；如需清掉旧数据可在浏览器控制台 `localStorage.clear()` 后刷新。

---

## T1 — 采购申请号自动生成（部门编号 + 流水号）

1. 进入「新建采购申请」。
2. 观察「采购申请号」字段：**提交/暂存前为只读占位提示**（"提交/暂存时自动生成"）。
3. 填写：标题、申请类型=物料采购、部门=**生产部**、期望日期、申请原因。
4. 点「暂存」或「提交申请」。
5. 预期：
   - 申请号自动生成为 `PR-PD-YYYYMMDD-NNN` 格式（例 `PR-PD-20260727-001`）。
   - 编号规则 = `PR` + 部门编号（生产部→PD，采购部→PU，设备部→EQ，技术部→TD，安全部→SD，质量部→QA，财务→FI，仓储→WH，销售→SA，人事→HR，行政→AD）+ 8位日期 + 3位当日流水。
   - 跳转到采购申请列表，新单据申请号符合上述规则，且同日同部门多次提交流水号递增。

---

## T2 — 物料号/名称拆分 + Excel 多行粘贴批量导入

1. 在「物料明细」区，确认列已拆分为：**物料号 | 物料名称 | 规格型号 | 单位 | 数量 | 预估单价 | 预估金额**。
2. **单物料录入**：在「物料号」列输入框输入编码（如 `MAT202405010001`）或名称关键字（如"钢板"）并下拉选择 → 物料名称、规格、单位、预估单价自动带出（只读展示，未匹配时标黄「未匹配」）。
3. **Excel 批量粘贴**（两种方式任选）：
   - 方式 A：在「物料明细」上方的「批量粘贴物料编码」文本框，从 Excel 复制多行物料编码（每行一个，或 TSV 首列即物料编码）直接 `Ctrl+V` 粘贴 → 自动批量新增行并匹配名称/规格/单位/单价。
   - 方式 B：在任意已有行的「物料号」输入框直接 `Ctrl+V` 粘贴多行编码 → 同样批量导入。
4. 预期：粘贴 2 行编码后明细新增 2 行，物料名称自动匹配正确；原 Excel 多列场景只取首列（物料编码）导入。
5. **框选复制**：在表格内用鼠标框选任意单元格文本 → 可像 Excel 一样复制（表格已开启文本可选中）。

---

## T3 — 来源选择（销售订单 / 生产工单 / MRP 需求）

1. 在「申请信息」区找到「来源类型」下拉：可选 **手工创建 / 销售订单 / 生产工单 / MRP需求**。
2. 选「销售订单」→ 出现「关联销售订单」输入框，点击选择一张销售订单。
3. 点「从销售订单拉取物料明细」按钮 → 该销售订单的物料行被填充进「物料明细」。
4. 同理验证：选「生产工单」→ 关联工单 → 拉取物料；选「MRP需求」→ 关联 MRP 建议 → 拉取物料。
5. 提交后，在采购申请详情/列表中可见来源类型与关联单据编号（来源信息已随单据保存）。
