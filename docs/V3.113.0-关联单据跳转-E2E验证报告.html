三、初轮 3 个「未跳转」的根因与修复

现象：首轮跑批时，出库→工单、物流→销售订单、发票→销售订单 3 个链接点击后 URL 不变。
根因：纯沙箱测试数据缺口，非代码缺陷。本地 D1 的 sales_orders 表对 org_e2e_sandbox 为空（store 水合覆盖前端 mock 致 salesOrders=[]），work_orders 也缺被引用的 WO20240512001。链接目标单号在目标 store 中不存在，故解析返回占位符不跳转。
佐证：同一套代码路径下，入库单的「上游采购单 / 下游批次」双向均跳通，证明点击机制、RelatedDocLinks、resolveRoute、ObjectPage 区块整条链路无功能缺陷。
修复：新增 scripts/seed/_seed_e2e_upstream.sql，向 org_e2e_sandbox 补插 SO202405003 / SO-VERIFY-001（销售订单）与 WO20240512001（工单）；重跑复验后 3 个链接全部跳通。该补种仅服务本地 E2E，生产环境数据自洽、无需此步。
