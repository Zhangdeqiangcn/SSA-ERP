## 五、B6-5 价格审批通过 → 价目表回写物料主数据标准价
**机制**：`priceStore.approvePriceApproval(id)` 事件驱动 → 生成/覆盖 `PriceListItem` 并置 `writtenBack:true`、`syncedAt`、`erpPriceId`；同步 `updateMaterial(materialId, { standardPrice })` 回写物料主数据。
| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 5.1 | 运行期调用 `approvePriceApproval('pa-001', {...})`（种子 `pa-001` 已含 `mat-001`/`mat-003`） | 审批完成 |
| 5.2 | 查价目表项 `pl-001` | `writtenBack === true`、`syncedAt` 有值、`erpPriceId` 形如 `ERP-pa-001-mat-001` |
| 5.3 | 查物料 `mat-001` | `standardPrice === 4050`（已回写主数据） |
| 5.4 | 调 `getActivePrice('ven-003','mat-001')` | 命中 `pl-001`（`ven-003` + `mat-001` + active） |

> ✅ 判定：审批即回写，价目表与物料主数据双向一致；成本核算优先级 `movingAvgPrice > standardPrice > price`，回写 `standardPrice` 不干扰 A4 移动平均价链路。
> ⚠️ 实现要点：`approvePriceApproval` 对**已存在的同键价目表项**（如种子 `pl-001` 已带 `sourceApprovalId:'pa-001'`）采用「覆盖回写标记」而非「跳过」，否则 writtenBack 永不置位。价目表项 `expiryDate` 须为**未来日期**（种子原 `2024-12-31` 已修正），否则 `getPriceOptions` 会按过期过滤导致 B6-6 带不出价。
