# SSA ERP B8 测试步骤与验收口径（V2.44）

> 版本：V2.44（2.44.0，构建于 2026-08-10）
> 战役：B8 MRP 增强（生产·物料域）
> 对标依据：对标文档 §14「B8 MRP 增强：消费 lotSize/leadTime/安全库存分层 + 提前期偏置排产」；§G6「MRP 未消费 lotSize/leadTime/安全库存分层」短板

## 一、变更摘要（B8 改了什么）
让真实 MRP 运算（`MRPPlan.tsx` 的 `computeNetRequirements` 纯函数）消费物料主数据参数，落实「计划可执行」：
1. **安全库存分层**：净需求 = max(0, 毛需求 + 安全库存 − 现有库存 − 在途)。安全库存不再被消耗。
2. **批量规则**：计划订单量按 `lotSize` 向上取整到整数倍，且不低于 `moq`（lotSize≤1 表示不取整；净需求为 0 则计划量 0）。
3. **提前期偏置排产**：需求日期取该物料被需求的最早销售订单 `expectedDeliveryDate`（缺省今天+30 天）；建议下单/开工日期 = 需求日期 − 有效提前期（采购用 `leadTime`，自制用 `cycleTime`）。
4. 结果表在「计划订单量」后追加五列：安全库存 / 批量 / 提前期(天) / 需求日期 / 建议下单日期。

## 二、手动走查（3 个用例）
进入「生产管理 → MRP 物料需求计划」，点右上角「计算净需求」。

- **用例 1 · 安全库存纳入**：以种子物料「钢板 Q235B (MAT202405010001)」为例，毛需求 700、现有库存 85、在途 30、安全库存 50 → 净需求应显示 **635**（而非旧公式的 585）。说明安全库存已被补回、不被消耗。
- **用例 2 · 批量取整**：同钢板 seed 配 `lotSize=100 / moq=50` → 计划订单量 = ceil(635/100)×100 = **700**（≥ moq 50）。若物料无 lotSize，则计划量 = 净需求（不取整）。
- **用例 3 · 提前期偏置**：同钢板 seed 配 `leadTime=7` → 建议下单日期 = 需求日期 − 7 天（早于需求日期）。若物料无提前期，则建议下单日期 = 需求日期。

## 三、验收口径
- 净需求 = 毛需求 + 安全库存 − 现有库存 − 在途（下限 0）。
- 计划订单量 = lotSize 向上取整整数倍，且 ≥ moq；净需求 0 时显示「无需补充」。
- 建议下单日期 ≤ 需求日期，差值 = 有效提前期。
- 结果表五列（安全库存/批量/提前期/需求日期/建议下单日期）正确渲染，无运行时报错（白屏）。

## 五、兼容性 / 回滚说明
- 仅改造 MRP 运算与结果展示，未触碰其他域 store；采购/仓储/质量/财务/门户逻辑不受影响。
- 物料主数据未配 `leadTime/lotSize/moq` 时，运算按「提前期 0 / 不取整」兜底，结果与旧行为单调兼容（仅净需求因子增加安全库存一项变化）。如某物料不希望纳入安全库存分层，可在物料主数据将该物料安全库存置 0。
- 种子仅给 mat-001/002/003 补 `leadTime/lotSize/moq` 以演示与确定化 E2E；其余物料沿用兜底逻辑。
