四、关键设计决策

① 密钥安全：电商平台 AppKey/AppSecret 只在后端（Functions）持有，前端只调 SSA 自有接口 /api/channels/<平台>——杜绝密钥泄露到浏览器。

② 复用优先：订单中台 store 直接复用 SSA 已有的 createEntityStore 工厂，调用方零改动；4 张新表沿用既有 org 隔离 + 审计列范式。

③ 诚实降级：未配置渠道凭证时后端返回明确错误（「未配置凭证」），不静默假成功。

④ 参考开源：适配器采用 OpenLinker 的 Port/Adapter 模式；契约测试参考 TORGNEXA 的 connector 能力清单门禁；OAuth 流程参考 Shopify 连接应用、抖音/拼多多开放平台授权码标准。

⑤ 登录即连接（OAuth 2.0 授权码）：start 下发平台授权 URL + state 防 CSRF Cookie；callback 校验 state 后用 code 换令牌并仅存后端（D1）；未配真实密钥时走模拟授权（界面与流程全真、令牌标"模拟"，绝不冒充真实平台）；AppKey/AppSecret/access_token 仅存服务端，前端永不接触。配置界面内置「配置应用（密钥）」「手动填令牌」「断开」三种模式，覆盖真实 OAuth / 临时调试 / 解绑全场景。
