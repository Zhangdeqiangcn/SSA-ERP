# SSA ERP V2.27 手动测试步骤（F6-1 ~ F6-4）

> 版本：V2.27（物料审批增强 + 询价需求来源）
> 用途：人工走查四大新功能，验证后直接交付。下次需要可直接取本文件。
> 关联 E2E：全量 128/128 已绿（含 `v33-material.spec.ts` 物料审批闭环）。

---

## 0. 前置准备

1. **启动开发服务器**（端口 3000）
   ```bash
   cd ssa-erp
   npm run dev          # 等价于 vite，访问 http://localhost:3000
   ```
2. **登录账号**：默认账号为 **admin**（角色 `admin`，可处理任意审批步骤，适合全流程自测）。
   - 如需模拟特定角色（如采购员 `buyer` 只看采购审核步骤），用右上角角色切换（switchRole）。
3. **数据重置**（可选）：物料审批申请初始为空，每次从「新增物料（审批）」发起。
   - 清空历史：浏览器开发者工具 → Application → Local Storage → 删除键 `ssa-erp-material-approval`（persist 键前缀 `ssa-erp-<domain>`）。
   - 或开一个无痕窗口。
4. **快速查 store（验证落库用）**：打开控制台输入
   ```js
   window.__ssaStores.useMaterialStore.getState().materials   // 看物料主数据
   window.__ssaStores.useMaterialApprovalStore.getState().materialApplications  // 看审批申请
   ```
   注意：`window.__ssaStores` 仅在 dev 环境挂载，生产构建无。

## T1 · 外购件审批（F6-1 物料信息 + F6-2 供应商回写 + F6-3 外购分支）

**目标**：验证采购审核时能看到物料基本信息、供应商 Autocomplete 回写、外购走"采购审核"分支。

| # | 操作 | 预期结果 |
|---|------|----------|
| 1 | 左侧「物料管理 → 物料审批」，确认当前队列状态 | 页面标题「物料新增审批队列」；列表可为空或历史 |
| 2 | 左侧「物料管理 → 新增物料」（或 `/material/create`） | 标题「新增物料（审批）」 |
| 3 | 填：物料名称=`测试外购件A`、物料分类=选第一项、单位=`个`、**自制/外购 = 外购**（或 外购件） | 字段可填 |
| 4 | 点「提交」(testid `material-submit`) | 提示「已提交物料新增审批，等待采购审核与批准生效」 |
| 5 | 进入「物料审批」页，点该申请行的「查看」按钮 | 打开对话框，标题「物料新增审批 · 申请单号」 |
| 6 | **F6-1 验证**：看对话框内「📋 物料基本信息」只读面板 | 含：物料名称、规格型号、自制/外购(📦外购)、物料类型、基本单位、型号、单价、备注；审批人无需切页即可看到上下文 |
| 7 | 顶部「流程追踪」 | 节点为：发起申请 → **采购审核** → 批准生效（当前高亮"发起申请"） |
| 8 | 当前步骤"发起申请"可编辑字段（名称/单位/规格/自制外购/物料类型/分类/安全库存等），点 `ma-approve-btn` | 提示「✅ 已提交至下一步「采购审核」」 |
| 9 | 当前步骤变"采购审核"，**F6-2 验证**：可编辑字段含 采购提前期(天)/最小订单量/最小包装量/**默认供应商**(Autocomplete)/采购单位/单位换算系数 | 字段齐全 |
| 10 | 「默认供应商」用 **Autocomplete** 搜索并选择一家供应商（如"上海宝钢…"） | 选中后同时回填供应商 ID 与名称（无需手填名称） |
| 11 | 填 LT=10、MOQ=100、MPQ=10、采购单位=个、单位换算系数=1，点 `ma-approve-btn` | 提示「✅ 已提交至下一步「批准生效」（已保存：采购提前期、最小订单量…）」 |
| 12 | 当前步骤"批准生效"，点 `ma-approve-btn` | 提示「✅ 物料已批准生效！编码：XXXX，采购属性（LT/MOQ/MPQ/供应商等）已写入物料主数据」 |
| 13 | **F6-2 落库验证**：进入「物料列表」(`/material/list`)，搜索该物料，打开详情 | 确认 默认供应商 / 采购提前期 / MOQ / MPQ 已写入物料主数据（也可在控制台查 `useMaterialStore`） |

## T2 · 自制件审批（F6-3 自制分支）

**目标**：验证自制件走"工艺审核"分支，且审核字段为工艺类而非采购类。

| # | 操作 | 预期结果 |
|---|------|----------|
| 1 | 「新增物料（审批）」：物料名称=`测试自制件B`、单位=个、**自制/外购 = 自制** | 字段可填 |
| 2 | 点「提交」 | 提示已提交审批 |
| 3 | 「物料审批」页 → 该申请「查看」 | 打开对话框 |
| 4 | 顶部「流程追踪」 | 节点为：发起申请 → **工艺审核** → 批准生效（第二节点是"工艺审核"，非"采购审核"——F6-3 分支生效） |
| 5 | "发起申请"提交 → 进入"工艺审核"步骤 | 当前步骤标签为"工艺审核" |
| 6 | **F6-3 自制分支验证**：可编辑字段为工艺类（工艺路线/工作中心/周期时间/报废率 等） | **不应**出现 LT/MOQ/MPQ/默认供应商 等采购字段 |
| 7 | 填工艺字段，点 `ma-approve-btn` → 批准生效 → 点 `ma-approve-btn` | 物料批准生效，编码生成 |
| 8 | 落库验证：物料列表查该物料，详情显示工艺属性 | 工艺字段已写入 |

> 双路径由 `draft.makeOrBuy` 驱动：=`make`→工艺审核；其它（含 `buy`/`purchased`）→采购审核。

## T3 · 询价单需求来源快速填充（F6-4）

**目标**：验证发起询价单时可按需求来源勾选行项，批量加入明细。

| # | 操作 | 预期结果 |
|---|------|----------|
| 1 | 左侧「供应链 → 询价单 → 新建」（或 `/price/inquiry/create`） | 打开询价单表单 |
| 2 | 填基本抬头（询价标题、供应商等） | — |
| 3 | 找到「📥 需求来源」区块，来源默认 = **手动输入** | 下方提示"请通过上方需求来源选择或手动添加物料"，无来源列表 |
| 4 | 切换来源 = **采购申请** | 显示「已审批的采购申请」列表（需系统内有 `status=approved` 的采购申请；无则提示"暂无已审批的采购申请"） |
| 5 | 展开某一单，勾选若干行项，点「批量加入明细(N)」 | 明细表出现对应行；行尾 Chip 显示「采购申请:单号」；物料名称/数量来自采购申请行 |
| 6 | 切换来源 = **新增物料** | 显示「外购件物料列表」（筛选 `makeOrBuy=buy` 或 外购件 或未设） |
| 7 | 勾选若干外购件，点「批量加入明细(N)」 | 明细出现，Chip 显示「新增物料」 |
| 8 | 切换来源 = **客户询价** | 提示"客户询价来源功能正在开发中，将支持从销售报价单/客户询价导入行项"（当前不可用） |
| 9 | 验证来源切换清空：切换来源类型后再看上方勾选计数 | 切换后已选计数归零（每次切换重置选择） |
| 10 | 提交询价单 | 明细行含来源标记，提交成功 |

> 注意：
> - 采购申请来源依赖系统已有「已审批」采购申请；测试前可先走一单采购申请审批。
> - 客户询价来源为开发中（alert 提示），本期不接数据。
