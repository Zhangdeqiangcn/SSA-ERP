# SSA ERP V2.32 手动测试步骤（A3 客户主数据建档）

> 版本：V2.32（2026-08-05）　模块：销售·客户主数据（A3）　专项 E2E：`e2e/v51-a3-customer.spec.ts`（5/5 全绿）
> 范围：仅销售订单接入客户主数据；报价/发票/退货/发货/项目等其他单据仍用 `customerName` 字符串冗余。

---

## 一、客户主数据建档（对标 SAP/金蝶/用友「信用账期主数据」）

### 1.1 客户列表
- 进入 **销售管理 → 客户**（侧边栏销售分组，订单上方）。
- 列表列：客户编码 / 名称 / 类型 / 联系人 / 电话 / 状态 / 信用状态。
- 信用状态：已用 ÷ 授信，超 90% 或超额标红。
- 点行跳转 **客户详情**（`/sales/customers/:id`）。

### 1.2 新建客户
- 点「新建客户」→ 填写：
  - 必填：客户编码（如 `C006`）、名称、类型（直供/经销商/代理/终端）、状态（启用/停用/黑名单）。
  - 信用：信用等级（AAA~C）、授信额度（数字）、账期（天，0/30/45/60/90）。
  - 开票：税号、开票抬头、开票地址、开票电话。
  - 银行：开户行、银行账号、账户名。
  - 联系人：姓名/电话/邮箱；地址；默认币种；默认税率；备注。
- 保存 → 跳转详情，store 中新增该客户（`window.__ssaStores.useCustomerStore` 可见）。

### 1.3 编辑 / 删除
- 详情页「编辑」→ 改授信额度/账期/开票信息 → 保存自动戳 `updatedAt`。
- 详情页「删除」→ 确认后从列表移除（已关联销售订单的客户仍可删除，订单侧保留 `customerName` 冗余）。

---

## 二、销售订单引用客户主数据 + 信用硬拦截（核心改造）

### 2.1 选客户（替代原自由文本）
- 新建销售订单 **销售管理 → 销售订单 → 新建**。
- 「客户」改为 **Autocomplete 下拉**（数据源 = 客户主数据），输入关键字匹配名称/编码。
- 选中后自动带出：客户编码、联系人、电话、默认币种、默认税率（回写表头）。
- 客户区下方实时显示 **信用占用提示**：已用 / 授信 / 可用（如「已用 ¥1,030,560 / 授信 ¥1,500,000 / 可用 ¥469,440」）。

### 2.2 正常提交占用信用（A3-2）
- 选 **C003 新源机械**（授信充足，已用 0）→ 加一行物料、单价/数量使价税合计 < 可用额度。
- 点「提交」→ 成功跳转订单列表；`customerStore` 中 C003 的 `usedCredit` 增加该订单价税合计（硬管控占用，非旧 Prospect 只增不减）。

### 2.3 超额硬拦截（A3-3，关键验证）
- 选 **C001 华润建筑集团**（授信 150 万，已用约 103 万，可用约 47 万）。
- 加一行物料，使订单价税合计 **超过可用额度**（如单价 100 万 ×1 台）。
- 点「提交」→ **页面顶部弹出红色错误 Alert「禁止提交：客户信用不足…」**，**停留在新建页、订单未写入**（区别于旧 Prospect 只警告不拦截）。
- 降单价至可用额度内 → 再次提交成功。

### 2.4 列表 / 详情跳转（A3-4 / A3-5）
- 订单列表「客户」列点击名称 → 跳转该客户主数据详情。
- 订单详情「基本信息」区客户名称可点击跳转；详情新增「客户主数据」区展示：信用等级/授信额度/已用/可用、账期、开票抬头/税号、开户行/账号；并与主数据实时联动。

## 三、回归关注点（A3 专项之外）
- 旧销售订单（无 `customerId`）仍正常显示 `customerName`，详情/列表不报错（兼容冗余字段）。
- `salesStore` persist 升级 v1→v2：刷新页面后旧订单按 `customerName` 自动回填 `customerId`（命中种子客户则跳转可用，未命中则仅显示名称）。
- 客户主数据页框架（DataTable/ObjectPage）与其他模块一致，无白屏/控制台报错。

---

## 四、验收结论
- A3 专项 E2E `v51-a3-customer.spec.ts`：A3-1 建档 / A3-2 正常占信用 / A3-3 超额硬拦截 / A3-4 列表跳转 / A3-5 详情关联，**5/5 全绿**。
- 信用管控由旧「字符串匹配 + 只警告」升级为「主数据 + 硬拦截 + 占用可扣减」，消除 `usedCredit` 只增不减、`as any` 逃逸等硬伤。
