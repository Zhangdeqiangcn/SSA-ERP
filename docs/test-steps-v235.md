## 0. 准备

1. 启动系统：项目根目录 `ssa-erp` 下运行 `npm run dev`，浏览器打开 `http://localhost:3000`。
2. **重要**：走查前先按 `F12` → Application → Local Storage → 右键 `Clear`，再刷新页面，确保读到 V2.35 的全新种子数据（否则旧 `ssa-erp-finance-ledger` 缓存会走迁移路径，虽然也能补齐 12 期，但状态可能带旧痕迹）。
3. 左下角/设置页版本号应显示 **V2.35**。

## 3. A6-② 凭证期间硬管控（核心）

### 3.1 已结账期间禁止新增凭证

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 3.1.1 | 回到 财务 → 期末结账，选 `2026-01`，依次点「损益结转」→「结账」 | 2026-01 变「已结账」 |
| 3.1.2 | 进入 财务 → 记账凭证（`/finance/vouchers`），点「**新增凭证**」 | 弹出「新增记账凭证」对话框 |
| 3.1.3 | 把「记账日期」改为 `2026-01-18` | — |
| 3.1.4 | 第 1 行：摘要「测试」，科目选「管理费用」，借方填 `1200`；第 2 行：摘要「测试」，科目选「银行存款」，贷方填 `1200` | 下方显示「借贷平衡」，保存按钮可用 |
| 3.1.5 | 点「**保存**」 | ❗**对话框不关闭**；列表页顶部出现**红色错误条**：「会计期间 2026-01 已结账，禁止新增凭证。如需调整请先在「财务 → 期末结账」执行反结账」 |
| 3.1.6 | 把「记账日期」改为 `2026-03-18`，再点「保存」 | ✅ 保存成功，绿色提示「凭证 记-… 已保存（制单）」，对话框关闭 |

> ✅ 判定标准：期间是**硬边界**——不是弹个警告还让你存进去，而是直接拒绝写库。

### 3.2 已结账期间禁止修改 / 删除 / 过账 / 冲销

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 3.2.1 | 先在**未结账**期间（如 2026-04）建一张制单态凭证 | 保存成功 |
| 3.2.2 | 去期末结账把 `2026-04` 结账（损益结转 → 结账） | 2026-04 变「已结账」 |
| 3.2.3 | 回记账凭证，找到刚才那张凭证，点「编辑」，改备注后保存 | 被拒：「会计期间 2026-04 已结账，禁止修改凭证…」 |
| 3.2.4 | 点该凭证的「删除」 | 被拒：「…禁止删除凭证…」；**凭证仍在列表中**（不是静默失败） |
| 3.2.5 | 点「审核」后再点「过账」 | 审核可通过（不改账），**过账被拒**：「…禁止过账…」 |
| 3.2.6 | 去期末结账把 2026-04「反结账」，回来重试过账 | ✅ 过账成功，写入总账明细 |

### 3.3 自动凭证也受保护

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 3.3.1 | 把当前月份对应期间结账（如今天是 2026-08，则结账 `2026-08`） | 期间变「已结账」 |
| 3.3.2 | 去 仓储 → 入库单，做一笔采购入库过账（触发 GR/IR 暂估自动凭证） | 自动凭证生成被拒（因走同一个 `createVoucher` 引擎），系统不会偷偷写入已结期间 |
| 3.3.3 | 反结账后重试 | ✅ 正常生成暂估凭证 |

> 说明：出库 COGS、发票校验、退货红冲等自动凭证同理，全部经 `createVoucher` 统一管控。

## 6. 已知说明

- 会计年度目前固定为 **2026**（`FISCAL_YEAR` 常量）。跨年度需求（多年度日历、年结）属后续增强项，不在 A6 范围内。
- 「审核 / 反审核」两个动作**不受期间管控**（只改凭证状态、不动总账）；真正会改变已结报表的「过账」被严格拦截。
- 老数据（V2.34 及以前的 localStorage）打开 V2.35 时会自动迁移：原有结账记录保留，缺失的期间自动补齐为「未结账」。
