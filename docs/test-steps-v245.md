# SSA ERP C1 测试步骤与验收口径（V2.45）

> 版本：V2.45（2.45.0，构建于 2026-08-05）
> 战役：C1 批次正反向追溯穿透视图（含序列号级一物一码溯源）（质量·仓储域）
> 对标依据：对标文档 §C「批次正反向追溯穿透视图（含序列号级）」

## 一、变更摘要（C1 改了什么）
新增**只读追溯引擎** `src/pages/Warehouse/TraceBatch.tsx`——纯函数 `buildTrace(batchNo, ctx)` 不改任何 store，消费 BatchRecord / InboundOrder / OutboundOrder / FinishedGoodsInbound / SerialMaster 做正反向穿透：
1. **反向上游（来源）**：批次 → 采购入库单（供应商 + 采购订单 sourceNo）；成品批次 → 生产工单 → 领料出库（耗用原料批次）→ 原料采购入库 → 原料供应商。
2. **正向下游（去向）**：原料批次 → 生产领料（工单）→ 成品入库（成品批次）；销售/调拨出库 → 客户。
3. **序列号级（一物一码）**：按 `serialNo` 匹配后取 `batchNo` 复用同引擎，并展示序列号信息面板（物料 / 批次 / 状态 / 客户 + 全生命周期 movements 轨迹）。

## 二、手动走查（3 个用例）
进入「仓储物流 → 批次追溯穿透」，在查询框输入批次号或序列号，点「追溯」（也可点快捷演示 Chip 自动填充）。

- **用例 1 · 成品批次反向上游穿透**：输入 `F20240620X`（成品批次），点追溯 → 反向上游应显示：生产工单 WO20240601001 → 生产领料耗用原料批次 B20240601X → 原料采购入库 IN20240601001 → 供应商「上海宝钢钢铁贸易有限公司」+ 采购订单 PO20240601001。
- **用例 2 · 原料批次正向下游穿透**：输入 `B20240601X`（钢板批次），点追溯 → 正向下游应显示：生产领料（工单 WO20240601001）→ 成品入库 F20240620X（钢结构框架 A 型）。
- **用例 3 · 序列号一物一码**：输入 `SN-2024-0001`，点追溯 → 序列号信息面板显示「交流接触器 CJX2」+ 关联批次 HQ20240508；反向上游显示供应商「深圳华强电气有限公司」；正向下游显示客户「宁波钢结构有限公司」。

## 三、验收口径
- 反向上游：采购批次 → 采购入库单（供应商 + 采购订单）；成品批次 → 工单 → 领料原料批次 → 原料供应商。
- 正向下游：原料批次 → 领料（工单）→ 成品批次；销售出库 → 客户。
- 序列号：serialNo 命中后取 batchNo 复用同引擎，并展示序列号信息面板 + 生命周期轨迹。
- 未找到批次/序列号时给出 warning 提示，不白屏、无 pageerror。

## 五、新增自洽种子链路（C1 闭环）
- 采购入库 `IN20240601001`（采购 / 上海宝钢 / PO20240601001 / 钢板批次 B20240601X）
- 批次 `bat-008`（B20240601X，关联 IN20240601001）
- 领料出库 `OUT20240601001`（pick → 工单 WO20240601001 → 耗用 B20240601X）
- 成品入库 `fin-002`（成品批次 F20240620X / 工单 WO20240601001 / 钢结构框架 A 型）
- 销售出库 `OUT20240610001`（售 mat-009 批次 HQ20240508 → 宁波钢结构）
- 序列号 `SN-2024-0001`（交流接触器 / 批次 HQ20240508 / 深圳华强入库 / 宁波钢结构发货 / movements 轨迹）

闭环：F20240620X ↔ B20240601X ↔ WO20240601001 ↔ IN20240601001（上海宝钢 / PO20240601001）+ OUT20240610001（宁波钢结构）+ SN-2024-0001。

## 六、兼容性 / 回滚说明
- 纯只读穿透计算，未改动任何出入库 / 批次 / 序列号写入逻辑，不影响现有业务域 store。
- 新增路由 `Sidebar` 仓储物流组「批次追溯穿透」(/warehouse/trace) + `App.tsx` lazy/Route，不影响其他页面。
