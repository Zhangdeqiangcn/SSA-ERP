# SSA ERP V2.30 凭证结构重构（A1）手动测试步骤

> 适用范围：财务管理 → 凭证管理（路径 `财务管理 → 凭证管理`，或直接访问 `/finance/vouchers`）
> 前置：dev server 已启动（`localhost:3000`），以有财务权限的账号登录；本版对**存量数据自动迁移**——首次进入凭证管理页，旧 `accountEntries` 会按 `voucherNo` 分组还原为凭证结构，无需手工操作。如需从干净环境验证可在浏览器控制台 `localStorage.clear()` 后刷新。
> 核心变更：扁平 `AccountEntry` 升级为 `Voucher{凭证头 + 分录行[]}`，保存前强制 **Σ借 = Σ贷** 平衡校验，凭证具备 **制单 → 审核 → 过账 → 冲销** 状态机。三大报表（资产负债表/利润表/现金流量表/科目余额表）取数口径不变，由派生层保证兼容。

---

## T1 — 存量分录迁移与列表统计卡

1. 进入「凭证管理」页。
2. 观察顶部**统计卡**：应显示 凭证总数 / 制单(待审核) / 已审核 / 已过账 / 已冲销 / **借贷不平** 六项计数，且数值与数据库一致。
3. 预期：
   - 存量分录已全部聚合为凭证（"共 N 张凭证 / M 条分录"）。
   - 若某张凭证借贷不平，会在「借贷不平」卡上计数（正常情况下应为 0）。
4. 点击任意一张凭证的「展开」箭头 → 显示该凭证的多条分录行（科目 / 摘要 / 借方 / 贷方）。
5. 预期：分录行科目、借贷金额与原始 `accountEntries` 一致。

---

## T2 — 新建凭证 + 借贷平衡校验

1. 点「新增凭证」按钮，打开制单对话框。
2. 填写：凭证日期、凭证字号、附件数；在分录区录入两行（科目从下拉选择，如"银行存款""管理费用"）：
   - 行 1：摘要"报销差旅费"，科目"管理费用"，借方 1000。
   - 行 2：摘要"报销差旅费"，科目"银行存款"，贷方 800。
3. 观察底部**实时合计**：借方合计 1000 / 贷方合计 800 / **差额 200**，并出现"借贷不平衡"提示，保存按钮**置灰禁用**。
4. 点「一键补平」按钮（或手动把行 2 贷方改为 1000）→ 差额归零，提示消失，保存按钮恢复可点。
5. 点「保存」。
6. 预期：凭证写入成功，状态为「制单(待审核)」，出现在列表顶部；借贷合计完全一致。

---

## T3 — 状态机全链路：制单 → 审核 → 过账 → 冲销

1. 在 T2 新建的凭证上点「审核」→ 状态变为「已审核」，出现「反审核」「过账」按钮。
2. 点「过账」→ 状态变为「已过账」，凭证进入总账（`accountEntries` 写入对应分录）；此时出现「冲销」按钮。
3. 点「冲销」→ 系统自动生成一张**红字凭证**（金额为负）并直接过账，原凭证状态变为「已冲销」，红字凭证出现在列表。
4. 预期：
   - 原凭证与红字凭证借贷金额互抵，**该科目净发生额归零**（可在科目余额表验证）。
   - 「已冲销」为终态，原凭证不再可编辑/删除/过账。
5. 反审核验证：对「已审核」状态的凭证点「反审核」→ 回到「制单」状态，可继续编辑。

---

## T4 — 状态筛选与检索

1. 在列表上方筛选区：
   - 「状态」下拉选「已过账」→ 列表仅显示已过账凭证。
   - 「会计期间」输入 `2026-08` → 列表仅显示该期间凭证。
   - 「关键字」输入某凭证号或摘要片段 → 列表实时过滤。
2. 预期：三种筛选可叠加生效，结果与筛选条件一致；清空筛选恢复全部。

---

## T5 — 报表兼容验证（取数口径不变）

1. 进入「财务报表 → 科目余额表」（或资产负债表/利润表）。
2. 确认过账凭证的分录已正确进入报表：
   - 科目余额表中该凭证涉及的科目「借方合计 = 贷方合计」（总账平衡）。
   - 资产负债表中资产 = 负债 + 权益 保持平衡。
3. 预期：A1 重构后报表取数与重构前完全一致（1 条分录 = 1 条 `AccountEntry`），**报表零改动、数据零差异**。

---

## 回归提示
- 编辑已有凭证时，分录行、科目、借贷金额正确回填；处于「已过账/已冲销」状态的凭证不可编辑（置灰）。
- 删除「制单」状态凭证会同步移除其派生分录。
- 红字冲销凭证在科目余额表中以负数呈现，与原凭证抵消后净额归零（已修复早期 `> 0` 判定导致红字行科目丢失的 bug）。
- 全量 Playwright E2E 已覆盖（用例 `e2e/v49-a1-voucher.spec.ts`：A1-1 存量迁移 / A1-2 平衡校验 / A1-3 状态机全链路 / A1-4 筛选检索 / A1-5 报表兼容，5 用例全绿）。
