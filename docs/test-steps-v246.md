# SSA ERP C2 测试步骤与验收口径（V2.46）

> 版本：V2.46（2.46.0，构建于 2026-08-05）
> 战役：C2 甘特图拖拽排产 + 负荷联动重排（生产域）
> 对标依据：对标文档 §C「甘特图拖拽排产 + 负荷联动重排 | 排产体验对标 PPDS」

## 一、变更摘要（C2 改了什么）
新增**甘特排产页** `src/pages/Production/GanttSchedule.tsx`——纯 CSS 甘特 + 原生 pointer 拖拽（不引第三方拖拽/甘特库）：
1. **5 大工作中心泳道**（DEFAULT_WORK_CENTERS）：切割 / 焊接 / 喷涂 / 装配 / 质检。工单按工艺路线**首工序** `mapCenter()` 映射主工作中心泳道。
2. **拖拽改期 + 前/后移一天按钮**：pointer 拖拽甘特条改期；前/后移一天按钮为确定性改期入口（E2E 友好），改期经 `productionStore.updateWorkOrder` 持久化。
3. **负荷（有限能力模型）**：工单在某中心占用当日即计满该中心日产能，利用率 = 当日重叠工单数 × 100%；峰值 > 100% 标红「超载」。
4. **负荷联动重排**：按优先级（urgent>high>normal>low）做同中心前向顺排，时长 = ⌈工单工时 / 日产能⌉、不重叠；重排后峰值利用率 ≤ 100%。

## 二、手动走查（3 个用例）
进入「生产管理 → 甘特排产」，观察 5 条工作中心泳道与工单条（按首工序映射）。

- **用例 1 · 前移改期并持久化**：切割中心泳道中 `WO-2024-0501`（wo-001）点条上「‹」按钮 → 计划开始日与结束日均减 1 天；刷新页面后仍为改期后日期（productionStore persist）。
- **用例 2 · 初始超载标红**：切割中心首工序同为「下料切割 / 激光切割」，wo-001(05-08~05-15) 与 wo-002(05-13~05-20) 日期重叠 → 切割中心峰值利用率 200%（>100%）并标红「超载」Chip。
- **用例 3 · 负荷联动重排**：点右上「负荷联动重排」→ 同中心工单按优先级顺排（wo-001 high 在前，wo-002 normal 在后），不再重叠；切割中心「超载」Chip 消失，峰值利用率降为 100%（≤100%）。

## 三、验收口径
- 泳道按工单工艺路线首工序映射主工作中心；首工序不同中心则不同泳道。
- 利用率 = 当日重叠工单数 × 100%；峰值 > 100% 视为超载（标红）。
- 前/后移一天：plannedStart 与 plannedEndDate 同时 ±1 天，持久化。
- 负荷联动重排：同中心不重叠，时长 = ⌈工单工时 / 日产能⌉，重排后峰值 ≤ 100%。
- 拖拽：pointer down 甘特条 → 移动换算天数 → pointer up 落库改期；无 pageerror / 白屏。

## 四、自动化 E2E
- 新增 `e2e/v67-c2-gantt.spec.ts`：C2-1（前移减 1 天并持久化）、C2-2（切割中心初始超载标红 + 峰值 >100%）、C2-3（重排后超载消失 + 峰值 ≤100% + 同中心不重叠），3/3 全绿（本次实测 49.4s）。
- 全量回归：52 spec / 216 用例（V2.46 = V2.45 的 51 spec/213 + v67 的 3 用例）。
