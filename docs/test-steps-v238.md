# SSA ERP V2.38 手动走查步骤（B3 工单完工回写）

> 本版主题：**B3 完工回写**（B 级第三役）
> 对标对象：SAP 生产收货 101（移动类型 101：成品按「工单实际生产成本」入账）—— `借 1405 库存商品 / 贷 5001 生产成本`，与 B2 委外收货（借 1405 / 贷 1408 / 贷 2201）对称。
> 自动化：`e2e/v59-b3-workorder-writeback.spec.ts` 6 用例全绿；**全量 E2E 44 spec / 180 用例 全绿**。
> 范围：工单完工自动①回写状态(completed)+合格数量(完工−报废)+实际完工日期+实际生产成本；②生成成品入库单(type='production')过账库存(wh-002 成品仓)+滚动成品移动平均价；③生成生产成本凭证（借 1405 / 贷 5001 = 工单 actualTotalCost）；④同步成品入库台账(FinishedGoodsInbound)。

---

## 0. 准备

1. 启动系统：项目根目录 `ssa-erp` 下运行 `npm run dev`，浏览器打开 `http://localhost:3000`。
2. **重要**：走查前先按 `F12` → Application → Local Storage → 右键 `Clear`，再刷新页面，确保读到 V2.38 的全新种子数据。
3. 设置页「系统信息 → 系统版本」应显示 **V2.38**。
4. 本版关键种子：
   - `wo-001`（工单 `WO-2024-0501`，产品 `PRD-FRAME-001`→`mat-fg-001`，状态 **在产**，计划 5 / 已完工 2）
   - `wo-002`（工单 `WO-2024-0502`，产品 `PRD-CABINET-001`→`mat-fg-002`，状态 **已下达**，计划 10 / 已完工 0）
   - `wo-003`（工单 `WO-2024-0490`，产品 `PRD-FRAME-001`，状态 **已完工**——用于验证幂等/拦截）
   - 成品物料主数据：`mat-fg-001 重型钢结构焊接架 H1200`（PRD-FRAME-001）、`mat-fg-002 电气控制柜体`（PRD-CABINET-001），valuationClass='FG'、priceControl='V'、带移动均价与库存金额。

## 1. 工单完工回写：状态 / 合格数 / 库存过账 / 生产成本凭证（B3-①，对标 SAP 101）

**路径**：生产 → 工单 → 工单详情（`/production/orders/wo-002`）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1.1 | 进入工单 `WO-2024-0502`（状态「已下达」） | 工单详情页可见，基本信息含产品 `PRD-CABINET-001 / mat-fg-002`、计划数量 10 |
| 1.2 | 点顶部「**生成成品入库**」按钮 | 弹出提示「工单已完工回写：成品入库、库存过账、生产成本凭证已自动生成」，自动跳转到 仓储 → 入库单 |
| 1.3 | 在工单详情/列表看 `WO-2024-0502` 状态 | 变为「**已完工 (completed)**」；合格数量 = 完工数 − 报废数（此处 = 10） |
| 1.4 | 去 仓储 → 入库单 | 能看到一条「**生产完工入库**」类型，仓库=成品仓，数量 10，状态「已过账」 |
| 1.5 | 去 物料主数据 看 `mat-fg-002` 当前库存 | 比完工前 **增加 10**（真实过账成品仓 wh-002，非仅记台账） |
| 1.6 | 去 财务 → 记账凭证 | 有一张凭证：`借 1405 库存商品` / `贷 5001 生产成本`，借贷合计相等（金额 = 工单 actualTotalCost，来源单号 = `IB-PROD-xxxx`） |
| 1.7 | 去 仓储 → 成品入库台账（`/warehouse/finished-goods`） | 能看到一条 `WO-2024-0502` 的成品入库台账，含 计划/实际/合格/报废 数量与批次号 |

> ✅ 判定标准：以前工单完工只是改状态、不碰库存也不出凭证；现在自动生成成品入库单过账库存，并按 SAP 生产收货 101 出 **借 1405 / 贷 5001** 凭证，成本 = 工单实际生产成本，借贷平衡。

## 2. 完工含报废：合格数 = 完工 − 报废，入库与凭证按合格数（B3-②）

**路径**：生产 → 工单 → 工单详情（`/production/orders/wo-001`）

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 2.1 | 进入工单 `WO-2024-0501`（产品 `PRD-FRAME-001`→`mat-fg-001`，计划 5） | 详情页可见 |
| 2.2 | 调 `completeWorkOrder('wo-001', { completedQuantity:5, scrapQuantity:2, actualTotalCost:600 })`（按钮入口为全量完工，此处演示报废口径） | 工单回写 完工=5、报废=2、**合格=3**、实际生产成本=600 |
| 2.3 | 去 物料主数据 看 `mat-fg-001` 当前库存 | 比完工前 **增加 3**（仅合格品入成品仓，报废不入） |
| 2.4 | 去 财务 → 记账凭证 | 凭证 `借 1405 / 贷 5001` 金额 = **600**（= 实际生产成本，非按合格数重算），借贷平衡 |

> ✅ 判定标准：合格数量 = 完工 − 报废，只有合格品过账入库；生产成本凭证金额 = 工单实际生产成本（actualTotalCost），与合格数脱钩口径正确。

## 9. 已知说明 / 范围边界

- **实际生产成本来源**：UI「生成成品入库」按钮按「完工数量=计划数量、报废=0」回写，不传 `actualTotalCost`（沿用工单既有 `actualTotalCost`；若种子未填则为 0，此时生产成本凭证金额为 0、不生成凭证，仅过账库存+台账）。E2E 通过显式传 `actualTotalCost` 验证凭证金额口径；后续可在完工弹窗中增加「实际生产成本 / 合格数 / 报废数」录入项。
- **凭证科目**：生产完工严格 `借 1405 库存商品 / 贷 5001 生产成本`，金额 = `roundAmount(actualTotalCost)`，借贷平衡；与 B2 委外收货（借 1405 / 贷 1408 / 贷 2201）对称但无委外发料与加工费暂估（自制件成本已在 5001 归集）。
- **成品仓**：成品统一入 `wh-002 成品仓`；移动平均价随完工入库滚动（金额≈数量×单价 恒等式保持）。
- **合格数量**：`qualifiedQuantity = completedQuantity − scrapQuantity`；仅合格品过账成品仓，报废不入。
- **幂等**：`completeWorkOrder` 对已 `completed`/`closed` 工单返回 `false`，不重复入库、不重复凭证、不动库存。
