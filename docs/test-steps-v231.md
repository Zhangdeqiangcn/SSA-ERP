# A2 采购订单税价拆分 — 手动走查步骤（V2.31）

> 配套自动化：`e2e/v50-a2-po-tax.spec.ts`（5 用例全绿）。
> 目标：采购订单支持币种 / 含税价开关 / 税率，行项目自动算税额与价税合计；三单匹配口径统一为「价税合计 vs 价税合计」并增加进项税对账。

## 1. 新建采购订单 — 表头税价控件
路径：采购订单 → 新建（或 `/purchase/orders/create`）
- 基本信息区应出现三个新控件：
  - **币种**（默认 CNY，可切 USD/EUR/JPY/HKD）
  - **价格类型**（默认「未税价」；可切「含税价」）
  - **默认税率**（默认 13%，可切 9/6/3/0；切换后带出到全部行，行内可单独覆盖）
- 不报错、页面正常渲染。

## 2. 行项目录入未税单价 → 自动算税额 / 价税合计
- 点「添加物料」，选一个物料（如「钢板 Q235B」），数量默认 1。
- 在「单价」列录入 `100`（未税价口径下代表未税单价）。
- 合计区三行应为：
  - 未税总额 **¥100.00**
  - 税额合计 **¥13.00**（= 100 × 13%）
  - 价税合计 **¥113.00**
- 行内「税额」「价税合计」列同步显示 13.00 / 113.00。

## 3. 切换为「含税价」录入 → 反向计算
- 把「价格类型」切到**含税价**。
- 单价列此时代表含税单价，录入 `113`。
- 合计区应为：
  - 未税总额 **¥100.00**（= 113 ÷ 1.13）
  - 税额合计 **¥13.00**
  - 价税合计 **¥113.00**
- 验证口径：含税价下系统先按价税合计反推未税，税额一致，不丢精度。

## 4. 提交后查看订单详情 — 三单匹配口径 + 进项税对账
- 填「订单标题」，选供应商（如「上海宝钢钢铁贸易有限公司」），录入单价后点「提交订单」。
- 进入订单详情，基本信息出现：**币种 / 价格类型 / 未税总额 / 税额合计 / 价税合计（蓝色加粗）**。
- 「三单匹配」区：
  - 采购订单显示**价税合计**（与发票同一口径，原「不含税 vs 含税」错配已修复）。
  - 发票区显示价税合计与**进项税对账**：PO 预估税额 vs 发票实际税额，一致显示「一致 ✓」，不一致显示差额。
- 物料明细表头含：税率 / 税额 / 价税合计 三列。

## 5. 采购订单列表 — 币种 / 价税合计列
路径：采购订单列表
- 列表新增「币种」列（CNY/USD…）与「价税合计」列（蓝色），原「未税金额」列保留。
- 存量 3 条 PO（po-001/002/003）显示不变（兼容 `totalAmount`），且价税合计与税额合计正确回填。

## 6. 三单匹配页 — 金额匹配维度
路径：财务 → 三单匹配（`/finance/three-way`）
- 表格新增「采购单价税合计」列与「金额匹配」列（一致/不符/—）。
- 摘要提示增加「N 张发票含税金额与采购单价税合计一致」。
- PO 价税合计与发票价税合计（发票 `totalAmount` 即价税合计）按统一口径比对。

## 兼容性确认
- 存量 3 条 mock PO 的 `totalAmount` 显示与历史一致，无回归。
- 税率用百分数整数（13/9/6/3/0），税额公式 `税额 = 金额 × 税率 / 100`，与销售模块口径一致。
