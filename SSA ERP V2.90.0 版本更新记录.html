二、逐条需求对照

1. 点击编号打开详情（原来点整行都会跳）

项目说明
改动前鼠标点行内任意位置都会跳转到详情页，容易误触（尤其想勾选或复制内容时）。
改动后整行不再响应点击；只有「编号列」单元格变成蓝色链接，点它才打开详情页。
编号列示例供应商编码、物料编码、客户编码、申请单号、订单号、询价单号、比价单号、审批单号、入库单号、出库单号、盘点单号、合同编号、项目编号。

2. 勾选行后：批量修改 + 批量删除

功能说明
批量修改弹窗列出该列表可改字段（如状态、类型、联系人、电话、邮箱、地址、信用额度等）。留空的字段不修改，只把填写了内容的字段统一应用到所选全部记录。
批量删除红色按钮，二次确认后删除所选记录（提示「已删除 N 条」）。
兼容性原有的「导出所选」「取消选择」保持不变；采购申请页原有的批量修改/删除能力保留不动。
字段真实性每个列表可改的字段都取自该实体详情页真实存在的字段，没有凭空造字段。

3. 批量导入（含模板下载）

项目说明
入口列表工具栏「导入」按钮 → 弹窗内可粘贴表格内容或上传 .xlsx/.xls/.csv 文件。
导入模板弹窗内「下载导入模板」按钮，按当前列表表头生成 Excel，照着填即可。
表头识别中文表头和英文表头都能认（如「供应商编码」和 code 都映射到编码字段）；中文状态会自动转成系统内部值（如「已批准」→ approved）。
主数据策略供应商 / 物料 / 客户：按编码匹配——已有则更新，没有则自动新建并生成编码。
单据类策略订单 / 询价 / 比价 / 审批 / 出入库 / 盘点：按单号匹配更新；匹配不到的行安全跳过（不新建），结束后提示「更新 N 条，跳过 M 条」，避免产生不完整的脏单据。
为什么单据类不自动新建？单据（如入库单）含明细行、关联单号等大量必填信息，Excel 里很难一次填全。强行新建会产生残缺单据，后续流程出错更难查。所以采取「只更新、不匹配就跳过并明确提示」的安全策略。

五、操作小贴士

  • 想打开详情：点蓝色编号（如 V202405001）；点其他单元格不会再跳转。
  • 想批量改：先勾选行 → 点「批量修改」→ 只填要改的字段 → 确认。
  • 想批量导入：点「导入」→ 先「下载导入模板」→ 按模板填好 → 粘贴或上传 → 看结果提示。
  • 导入前建议：先小批量试 2~3 条，确认映射无误再整批导入。
