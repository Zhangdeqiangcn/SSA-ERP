二、变更详情

2.1 打印模板预览数据补全物料编码

问题：打印预览的明细表（items）首列「物料编码」始终为空——因为样例数据 SAMPLE_RECORDS 里只有 materialName，没有传 materialCode。

修复：给全部 9 个有 items 的业务实体的样例数据补上 materialCode：

  • purchaseOrder — MAT-Q235B-1.5（冷轧钢板）
  • salesOrder — MAT-ZJ-001（精密轴芯）、MAT-ZJ-002（轴承座）
  • salesQuotation — MAT-CG-003（连接法兰）
  • salesContract — MAT-FRAME-01（精密零部件年度包）
  • bom — MAT-BODY-001/MAT-GEAR-001/MAT-BEAR-001/MAT-SEAL-001（减速机全 BOM）
  • inquiry — MAT-SS-304（不锈钢板）
  • workOrder — MAT-BODY-001/MAT-GEAR-001（工单物料）
  • purchaseRequest — MAT-LUBE-001/MAT-WELD-001（生产辅料）
  • warehouseOutbound — MAT-ZJ-001（出库物料）

文件：src/pages/Settings/PrintTemplateTab.tsx

2.2 订单模板表格加「物料编码」列

问题：订单模板编辑对话框的物料列表表头只有「物料/规格/单位/数量/单价/删除」6 列，TemplateItem 数据结构虽有 materialCode 字段但 UI 未渲染。

修复：

  • 表头在「物料」后新增「物料编码」列
  • 表格行用等宽字体（monospace）+ 蓝色显示 materialCode，与物料名称视觉区分
  • 选择物料后自动从 materialStore 填充 materialCode（原有逻辑不变）

文件：src/pages/Settings/OrderTemplateTab.tsx

2.3 页眉页脚结构化配置引擎（核心新功能）

旧状态：PrintTemplate 只有 headerText: string 和 footerText: string（纯文本），PrintPreview 固定居中渲染。

新状态：扩展为 HeaderFooterConfig 结构化配置对象（12 个属性）：

属性类型说明
textstring文本内容（支持 \n 换行和 {now} 时间占位符）
align'left'|'center'|'right'水平对齐方式
fontSizenumber (px)字号，0=继承默认
fontWeight'normal'|'bold'字重
colorstring (CSS)文字颜色
imageUrlstring (URL)图片 URL（公司 logo 等），留空不显示
imageHeightnumber (px)图片高度
imagePosition'left'|'right'图片位置（相对于文本行）
stampUrlstring (URL)电子印章图片 URL，留空不显示
stampSizenumber (px)印章尺寸
showDateboolean是否自动追加打印时间

2.4 PrintPreview 渲染升级

新增 renderHeaderFooter(config, fallbackText, isHeader) 函数：

  • 读 config 应用对齐/字体大小/字重/颜色样式
  • 支持左侧或右侧图片（logo），按 imagePosition 定位
  • 支持电子印章图片绝对定位叠加（页眉右下角 / 页脚右下角）
  • 自动处理 {now} 占位符替换为当前时间
  • showDate=true 时自动在文本末尾追加「打印时间：xxx」
  • 向后兼容：无 config 时使用默认值（居中、默认字号、无图无章）

2.5 PrintTemplateTab 编辑对话框升级

页眉/页脚从两个纯文本框升级为「高级设置」面板：

页眉高级设置
  • 对齐方式（左/中/右）下拉选择
  • 字号(px) 数字输入
  • 字重（常规/粗体）下拉选择
  • 文字颜色（CSS 色值）
  • 自动追加打印时间（复选框）
  • 图片 URL（logo 地址）
  • 图片位置（左侧/右侧）
  • 图片高度(px)
  • 电子印章图片 URL
页脚高级设置
  • 同上 9 项控件（独立配置）
  • 默认自动追加打印时间

双向同步：简单文本框与高级面板的 text 字段双向绑定，改任一处另一处同步更新。

2.6 向后兼容与数据迁移

  • headerText/footerText 字段保留（标记 @deprecated），旧代码仍可读写
  • persist version 1→2 + migrate 函数：自动给旧模板补 headerConfig/footerConfig（从原 text 字段迁移）
  • PrintPreviewButton.buildFallback() 补默认 config（未配置模板时的兜底渲染）

四、使用指引

查看物料编码

  1. 打开任意单据（采购/销售/报价等）→ 点「打印」→ 明细表首列即显示物料编码
  2. 打开系统设置 → 打印模板设计器 → 选业务实体 → 右侧实时预览即可看到物料编码列
  3. 打开系统设置 → 订单模板管理 → 编辑任意模板 → 物料列表第二列即显示物料编码（蓝色等宽字体）

编辑页眉页脚

  1. 打开系统设置 → 打印模板设计器
  2. 选业务实体 → 点「编辑」按钮进入模板编辑
  3. 上方简单文本框可直接输入页眉/页脚文字（与高级面板同步）
  4. 向下滚动到「页眉高级设置」面板：
    • 选对齐方式（左/中/右）
    • 填字号和字重
    • 填文字颜色（如 #1e40af 或 red）
    • 填图片 URL（公司 logo 的网络地址或 Base64 data URI）
    • 选图片位置（左侧/右侧）
    • 填电子印章图片 URL（PNG 透明底推荐）
  5. 同样操作「页脚高级设置」面板
  6. 点「保存」→ 右侧预览实时刷新 → 确认效果后点「打印」

粘贴图片/电子印章的方法

  • 网络图片：直接把图片 URL（如 https://example.com/logo.png）粘贴到「图片 URL」输入框
  • 本地图片：先把图片上传到可访问的服务器/OSS，再填 URL；或把图片转 Base64 后填入（格式 data:image/png;base64,...）
  • 电子印章：准备一张 PNG 透明底印章图片，上传到可访问地址，URL 填入「电子印章图片URL」→ 印章会以半透明方式叠加在页眉右下角或页脚右下角
