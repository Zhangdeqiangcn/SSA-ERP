SSA ERP V2.74.3 版本更新记录

发布日期：2026-09-01 ｜ 版本号：V2.74.3 ｜ 部署：a7572d01（canonical ssa-erp.pages.dev 已同步）

一、变更概览

核心目标：消除供应商主数据双数据源。V2.74.2 让开放网关直写 D1 vendor_master，但前端 vendorStore 仍写 app_state Blob，两套来源并存（前端与网关看到的供应商可能不一致）。本次把前端也接到 vendor_master，前端与网关真正同源。

模块改动关键事实
vendorStore移除 persist+backendStorage(app_state Blob)，改经 vendorApi 直连 D1 vendor_master双源根治；离线/未登录回退内存 mockVendors；首次空库从旧 app_state 一次性回填
后端 /api/vendors会话端点从旧 vendors 门户表改指 vendor_master；新增 POST 创建；[id] 补 JSON 扩展列与网关 open/vendors 同一张表
迁移 0017vendor_master 补 6 个 JSON 扩展列D1 不支持 ADD COLUMN IF NOT EXISTS，用纯 ALTER + schema_migrations 守卫
RLSvendor_master:'own'（采购看自己供应商）与网关/会话写操作归属校验一致
MSW/api/vendors CRUD 去 success 包裹、同构真实端点、补 PUT/DELETEDEV 联调一致

二、同源验证（真实 session 打真实生产 D1）

  • ✅ 同源创建：前端路径 POST /api/vendors 创建 → 网关路径 GET /api/open/vendors 立即可见同一条
  • ✅ 同源更新：前端 PUT /api/vendors/:id 改 credit_limit → 网关 GET 反映一致
  • ✅ 同源删除：前端 DELETE /api/vendors/:id → 网关 GET 该供应商消失

顺带修复实测暴露的 PUT 500

根因：绑参 body.code 等未传字段以 undefined 传入 D1（D1 不接受 undefined）。修复：绑参统一 ?? null + 写操作 try/catch 返回错误明细便于诊断。

四、使用提示与边界

  • 在线优先：登录后供应商主数据来自 vendor_master（与网关同源）；离线/未登录时回退本地 mock，页面不白屏但不持久。
  • 存量迁移：首次访问空库会从旧 app_state（或 mockVendors）自动回填 vendor_master 一次，之后以 D1 为准。
  • 评级记录：ratingRecords 暂用浏览器 localStorage 缓存（非 D1 表），刷新不丢但不跨设备；后续可独立建表。
  • 字段覆盖：vendor_master 已补齐 blacklist_reason_history/profile_pending/custom_fields 等 JSON 扩展列，覆盖 Vendor 业务模型全部字段。
