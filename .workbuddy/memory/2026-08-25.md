## P2 合规与智能化 Phase 1-2 完成

### P2-01 真正 ChatBI
- 新建 POST /api/chatbi/analyze API
- 支持7种查询类型：销售趋势、库存水平、供应商质量、采购状态、财务摘要、工单状态、客户列表
- 前端 ChatBI.tsx 替换 MOCK_RESPONSES，接入真实 D1 查询
- 支持历史记录和追问功能

### P2-02 异常预警规则引擎
- 新建 GET /api/alerts API
- 四类预警真实计算：
  - 库存低于安全库存（materials + inventory_records JOIN）
  - 逾期采购订单（purchase_orders 表）
  - 逾期销售订单（sales_orders 表）
  - 临期物料（inventory_records.shelf_life_status）
  - 信用超额客户（customers 表）
- AlertMonitor 组件接入真实 API，支持刷新重试
- 新增待审批单据统计

### P2-03 敏感字段屏蔽（RLS 强化）
- 新建 GET /api/protected-data/[type] API
- 按角色动态脱敏：
  - admin：不脱敏
  - manager：屏蔽财务字段（bank_account/tax_code）
  - staff：额外屏蔽信用金额
  - vendor：屏蔽自身敏感信息
- 脱敏策略：字符串打码(前2后2)、数值归零
- 支持4种数据类型：vendors/customers/sales-orders/purchase-orders
