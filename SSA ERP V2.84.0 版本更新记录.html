本次变更：C9 物料替代料组 + 优先级（BOM/生产灵活可配硬缺口闭合）

1缺口确认：主计划第 361 行把 C9 列为 🔴 零实现硬缺口（对标 AlternativeBOM/substitute 无源码匹配）；强哥指令「继续」后自动进入下一个对标净缺口。
2范围拍板：强哥选定「核心主数据 + UI 提示」+「主物料→替代料优先级列表」建模（互替 A↔B 由用户双向各录一行），工期最短、回归面最小。
3数据模型：新增迁移 0038_material_substitutes.sql（material_substitutes 表，全标量字段）：主物料编码 materialCode + 替代料编码 substituteCode + 优先级 priority + 替代类型 substituteType（完全 full / 部分 partial）+ 替换比例 conversionRatio + 生效起/止 + 原因 + 备注 + 审计列；索引 org / 主物料编码。
4后端零新增函数：实体注册表 ENTITY_RESOURCES 加 materialSubstitute 资源（通用实体端点 /api/entities/materialSubstitute，按组织编号隔离 + 行级权限共享主数据 + 写审计），前端经 entityRepo 增删改查，与 V2.81/82 双通道根治范式完全一致。
5前端 store：src/types/material.ts 加 MaterialSubstitute 接口（含 SubstituteType）；materialStore 加 substitutes 状态 + loadSubstitutes（随物料加载拉取、首次空库回填演示态、离线回退内存）+ addSubstitute/updateSubstitute/removeSubstitute（乐观更新 + 即发即弃异步写回云端数据库 D1）。
6界面：物料详情页新增「替代料组」区块（按优先级升序展示、弹窗增删改，替代料从物料主数据下拉选择，自动带出编码/名称）；BOM 详情物料行带「可替代」徽标提示（只读、低风险）。
