一、强哥的诉求（本版源起）

  • V2.88.0 的页眉页脚编辑「占用面积太大、功能不实用」，要求改好。
  • 像 Word 一样——选中文字时弹工具栏（字体 / 字号 / 颜色）。
  • 图片要在页眉页脚框内直接本地上传，并能鼠标拖动调整位置。
  • 电子印章其实就是图片，不用单独占一行，合并到图片功能里。
  • 打印内容里要加上审批记录、时间等选项。

二、核心变更（7 项）

  • ① 换引擎：引入 mui-tiptap（基于 Tiptap v3 / ProseMirror，原生贴合 MUI 主题），替换 V2.88 的 22 个页眉页脚表单控件；编辑对话框高度缩减约 60%。
  • ② 选中弹工具栏：选中文字即弹出气泡菜单（加粗 / 斜体 / 下划线 / 字体颜色 / 对齐），顶部工具栏同样提供，所见即所得。
  • ③ 图片框内直传：页眉页脚框内直接选本地图片（MenuButtonImageUpload），自动转 base64 内嵌富文本——离线 / 内网也能打印、随模板持久化，不再手填 URL。
  • ④ 印章合并为图片：删除独立的「印章URL」字段，印章作为透明底 PNG 用同一上传功能放入，并用 ResizableImage 扩展支持拖拽缩放与定位。
  • ⑤ 打印附加选项：新增 extraOptions（审批记录 / 制单人 / 制单时间 / 审核人 / 审核时间 / 页码）；预览按勾选渲染审批记录表、制单人 / 审核人信息，页码用打印 CSS 计数器（第 X 页 / 共 Y 页）。
  • ⑥ 数据结构简化：HeaderFooterConfig 从 12 字段收敛为 { html, showDate }；persist 版本 2→3 + 迁移把 V2.88 旧 12 字段（legacyConfigToHtml）与 V2.87 纯文本（textToHtml）自动合成为富文本，老用户升级无感。
  • ⑦ 顺手修隐患：修复 manual.tsx 版本记录 v2880 块遗留的缺 ] 语法问题（tsc 原漏检，本轮暴露并修复）。
