SSA ERP 系统测试步骤清单

版本 V2.86.0（钢材供应链版）· 从基础配置到业务全链路 · 含字段权限（V2.86 核心）回归

关于「公司配置」：系统侧边栏没有单独叫"公司配置"的菜单。初始化公司的真实入口在 「系统设置」页里的 组织配置 和 基础配置 两个页签。本清单第一步就从这里开始。 另外，系统自带一键回归工具 「测试与诊断 → 全流程自检」（路径 /test/flow），建议放在最后一步整体验收。
🧭 测试顺序总览（11 个阶段）： ① 基础配置 → ② 主数据 → ③ 采购到付款 → ④ 仓储物流 → ⑤ 质量 → ⑥ 生产 → ⑦ 销售到收款 → ⑧ 财务 → ⑨ 移动端（渐进式网页应用）→ ⑩ 字段权限验证（V2.86 核心回归）→ ⑪ 全流程自检

第一阶段：基础配置（系统设置）初始化起点

#操作路径（侧边栏点击）验证点
1.1系统设置 → 组织配置（OrgTab） 新建/确认：公司、工厂、库存地点、采购组织、销售组织。组织结构树能正常显示与展开。组织是后续所有单据的归属主体
1.2系统设置 → 基础配置（BasicConfigTab） 填写公司名称、本位币（如人民币）、默认税率、会计期间、界面语言。保存后刷新页面，配置仍在。
1.3系统设置 → 编号规则（NumberingTab） 设采购订单 / 销售订单 / 物料编码前缀与流水号规则。新建单据时自动带出编号。
1.4系统设置 → 数据权限（DataPermissionTab） 切换角色，勾选要隐藏的敏感字段（如库管员隐藏"物料标准价"）。见第十阶段联动验证。
1.5系统设置 → AI 模型（AIConfigPage） 确认默认模型为 Agnes 2.5 Flash（国产大模型服务）。进入任意 C6 助手对话能正常返回解答。
1.6系统设置 → 税务配置（TaxConfigPage） 填入企业税号。数电票真实核验通道需另配服务商密钥（未配则走模拟兜底）。
1.7系统设置 → 移动门户（MobileTab） 显示真实二维码（编码地址+/m），"打开移动门户"按钮可跳转渐进式网页应用。

第二阶段：主数据业务地基

#操作路径验证点
2.1主数据 → 物料管理 → 物料分类 建立物料分类层级（如原材料/半成品/产成品）。
2.2主数据 → 物料管理 → 物料列表 新建物料，填写评估类、价格控制、标准价/移动平均价、当前库存。列表可增删改查、可搜索。
2.3主数据 → 物料管理 → 评估类与价控 确认评估类与计价方式映射正确（标准价/移动平均价）。
2.4物料详情 → 替代料组（V2.84/85） 为物料添加替代料，设优先级、替代类型、替换比例。列表按优先级升序显示。
2.5主数据 → 供应商管理 → 供应商列表 新建供应商，填评级、风险评分、黑名单标记。供应商门户配置可访问。
2.6销售管理 → 销售管理 → 客户主数据 新建客户，填授信额度（creditLimit）。V2.86 字段权限：非特权角色此处应显示屏蔽。

第三阶段：采购到付款供应链起点

#操作路径验证点
3.1供应链 → 采购管理 → 采购申请 新建申请，选物料/数量，提交进入审批流。
3.2供应链 → 采购管理 → 采购订单 由申请转订单或新建，关联供应商+物料，自动带出编号（见 1.3）。
3.3审批中心 → 采购审批 审批人登录可看到待办，审批通过/驳回，状态回写订单。
3.4供应链 → 采购管理 → 交期跟踪 订单交期、催货进度可跟踪。
3.5采购管理 → 框架协议 / 信息记录 / 货源清单 三种采购主数据可建立，货源清单影响后续货源建议。
3.6财务与报表 → 财务管理 → 三单匹配 采购订单 / 收货 / 发票三方匹配，差异可标红。
3.7财务管理 → 付款计划 基于发票生成付款计划，到期提醒。

第四阶段：仓储物流实物流动

#操作路径验证点
4.1供应链 → 仓储物流 → 报检单 来料报检，关联后续检验单。
4.2仓储物流 → 采购入库 选待入库单，录实收数，过账后真实扣减/增加库存（联动 2.2 当前库存、4.3 查询）。
4.3仓储物流 → 库存查询 入库后数量实时更新；可按物料/批次筛选。
4.4仓储物流 → 库存盘点 建盘点任务，录实盘，差异自动调库存（实盘−账面）。
4.5仓储物流 → 库龄分析 库存金额（stockValue）按 ABC 分类与呆滞料展示。V2.86 字段权限：非特权角色此处金额显示屏蔽。
4.6仓储物流 → 条码打印 打印物料/库存条码（一维码 Code 39 规则，与移动端扫码一致）。
4.7仓储物流 → 成品入库 / 出库管理 成品入库关联工单；出库发料扣库存、批次先进先出。
4.8仓储物流 → 跨组织转储 / 库存调整 / 批次追溯穿透 三种库存操作可完成，批次追溯能穿透来源。

第五阶段：质量来料/成品把关

#操作路径验证点
5.1生产与质量 → 质量管理 → 检验任务 来料/成品检验任务可领取、录入结果、判定合格/不合格。
5.2质量管理 → 检验标准 / AQL抽样 标准与抽样方案可被检验任务引用。
5.3质量管理 → 检验批/COQ（质量成本） 鉴定成本（inspectionCost）展示。V2.86 字段权限：非特权角色此处金额显示屏蔽。
5.4质量管理 → 不合格品 不合格自动隔离，处置方式（让步/退货/报废）联动库存扣减 + 自动生成会计凭证。
5.5质量管理 → 8D / PDCA / SPC / COA合格证 改善工具与合格证可生成，SPC 控制图能绘制。

第六阶段：生产制造执行

#操作路径验证点
6.1生产与质量 → BOM管理 → BOM列表 多层物料清单（BOM）可建、可展开（实例+扁平清单视图）。
6.2生产管理 → 工艺路线 工序、工时、设备参数可定义。
6.3生产管理 → 工单管理 工单创建、发料、完工报告。BOM 带替代料徽标提示。
6.4生产管理 → MRP计划 运算净需求，替代料自动展开（V2.85）；缺料时给出替代料建议。
6.5生产管理 → 工序报工 工序完工汇报，倒冲扣料。
6.6生产管理 → 成本归集 标准/实际/差异/合计（cost）展示。V2.86 字段权限：非特权角色此处成本显示屏蔽。
6.7生产管理 → 详细排程 / 甘特排产 锁单/锚定生效，甘特图可拖拽重排。
6.8生产管理 → 委外加工 / 重复制造 / MES集成 三类生产模式可跑通（产线+周期+报工倒冲）。

第七阶段：销售到收款面向客户

#操作路径验证点
7.1销售管理 → 意向客户 线索录入、跟进、转化。
7.2销售管理 → 客户主数据 授信额度管理（见 2.6）。V2.86：非特权角色看不到授信。
7.3销售管理 → 销售订单 订单含客户名、单价、订单金额。V2.86：库管/采购/物流等角色客户名与金额显示 ***。
7.4销售管理 → 可用量承诺（ATP） 基于库存+在途给出可承诺量。
7.5销售管理 → 销售合同 / 报价 / 开票 合同、报价单、销售发票可生成并关联订单。
7.6销售管理 → 物流发货 发货计划、物流跟踪；发货确认联动库存。
7.7销售管理 → 三方销售 / 返利管理 三方业务与返利计算可跑通。

第八阶段：财务业财一体

#操作路径验证点
8.1财务管理 → 发票管理 上传发票图片，光学字符识别抽取结构化字段（V2.80）；无配置回退正则。
8.2财务管理 → 凭证列表 借/贷金额（voucherAmount）展示。V2.86：非财务角色此处金额显示屏蔽。
8.3财务管理 → 会计分录 / 科目余额表 / 科目表 凭证生成分录，科目余额正确累算。
8.4财务管理 → 三单匹配 见 3.6，差异可追踪到具体订单/收货/发票。
8.5财务管理 → 税务核算 / 数电票核验 数电票查验走真实通道（配密钥）或模拟兜底，界面标注真/假通道。
8.6财务管理 → 财务报表 / 三大报表 / 期末结账 报表可取数；期末结账锁定期间。
8.7财务管理 → 应收 / 应付 / 资金 / 预算 / ESG报告 各子模块可打开并取数。

第九阶段：移动端（渐进式网页应用）强哥重点

#操作路径验证点
9.1移动门户 /m → 扫码入库 选待入库单 → 扫物料条码（一维码 Code 39，内容为物料编码大写）→ 录实收 → 提交过账，真实写入库存（与桌面 4.2 同源）。
9.2移动门户 → 出库 / 盘点 / 质检 三个作业 Tab 均可用，逻辑与桌面端一致（V2.78+ 真功能）。
9.3移动门户 → 消息 即时消息可收发（V2.80）。
9.4手机"添加到主屏幕" 可安装为全屏应用，离线壳可启动。

第十阶段：字段权限验证（V2.86 核心回归）本版重点

本阶段验证 V2.86.0 的字段级权限覆盖全部模块。统一引擎：dataPermissionStore； 对不应看到金额/成本/授信的角色（库管、质检、班长、物流、供应商、采购、研发工程等）自动隐藏敏感字段，显示为 ***； 系统管理员、财务主管、会计等特权角色全部可见。
#操作路径 / 操作验证点
10.1用 系统管理员 登录，浏览各模块 物料标准价/移动平均价、库存金额、鉴定成本、生产成本、凭证金额、客户授信、销售客户名与金额 —— 全部可见。
10.2切换 库管员 角色 → 物料列表 / 库龄分析 物料标准价、移动平均价、库存金额 显示 ***。
10.3切换 质检员 角色 → 物料 / 检验批COQ / 销售订单 物料价格、鉴定成本、销售客户名与金额 显示 ***。
10.4切换 采购员 角色 → 销售订单 / 质量 / 财务 销售单价与金额、客户名、鉴定成本、凭证金额 显示 ***；但采购价对其可见。
10.5切换 供应商 角色（供应商门户）→ 物料 / 质量 / 生产 / 财务 物料价格、库存金额、生产成本、鉴定成本、凭证金额 均显示 ***（供应商不应看到买方成本）。
10.6平台 → 字段级权限（FieldPermissions 页） 页面改指统一引擎，列出全部已配置规则（角色×字段矩阵）。
10.7系统设置 → 数据权限 总开关 字段级屏蔽独立于总开关、常开生效（关闭总开关不影响字段屏蔽）。

第十一阶段：全流程自检（系统自带回归）整体验收

#操作路径验证点
11.1测试与诊断 → 全流程自检（/test/flow） 一键运行系统自检，关注 PASS / FAIL 数量。本版生产门禁基线：PASS 240 / FAIL 0。
11.2测试与诊断 → 使用说明书 说明书已登记 V2.86.0 条目，可查阅版本变更。
