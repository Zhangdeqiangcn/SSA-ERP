SSA ERP V2.87.0

2026-09-09 — 自定义审批流程（新建 + 发布审批 + 组织隔离可见）

📋 结论先行

本版实现自定义审批流程全功能闭环：用户可从零创建全新业务场景的审批流（选节点/配条件/设可见角色），草稿提交后经管理员批准才生效，已发布流程按组织+角色隔离可见。扩展现有 approvalFlowStore 引擎而非另起炉台，复用全部既有节点编辑器/条件引擎/FlowTracker 链路。

🏗️ Store 层变更

  • ApprovalFlowConfig 新增 7 个字段：status / createdBy / approvedBy / orgId / visibleRoles / description / createdAt / approvedAt
  • 新增 5 个方法：addCustomFlow / submitForApproval / approveFlow / rejectFlow / deleteCustomFlow
  • persist 版本 1→2，migrate 自动给旧流程补 status='system'
  • getApprovalFlow / getEffectiveSteps 仅返回 system + published 流程

🎨 UI 层变更

  • ApprovalFlowTab 顶部加 Tab 切换（系统预置 / 自定义）
  • 「新建自定义审批流」按钮 + 创建对话框（名称/模块标识/描述/可见角色）
  • 自定义流程列表分状态展示（草稿/待审/已发布）
  • 待审区域独立高亮，支持一键批准/驳回
  • 侧边栏「审批中心」新增「自定义审批流程」入口

🔄 流程状态机

状态说明可执行操作业务层可见
system 系统预置（13 条原始流程） 编辑、启停、重置 ✅ 可见
draft 草稿（新建或被驳回） 编辑节点、提交审核、删除 ❌ 不可见
pending 待管理员审核发布 批准、驳回、删除 ❌ 不可见
published 已发布生效 查看（不可编辑/删除） ✅ 可见（受 visibleRoles 过滤）

🔒 组织隔离与角色可见性

  • visibleRoles 为空 → 全部角色可见该流程
  • visibleRoles 非空 → 仅列表中角色 + admin 可见
  • orgId 隔离 → 不同组织的用户互不可见对方自定义流程
  • 读取器 getVisibleCustomFlows(currentRole, orgId) 封装全部过滤逻辑
